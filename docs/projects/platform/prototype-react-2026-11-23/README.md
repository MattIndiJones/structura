# Prototype React + SVG du 23/11/2026

Référence visuelle et d'interaction de la nouvelle interface : version C, adoucie, en bleu nuit
avec accent ambre. Ouvrir `index.html` dans un navigateur connecté à Internet (React, htm et les
polices viennent de CDN).

**Ce dossier n'est pas du code de production.**

- `engine.js` est un moteur GBM de démonstration. Il ne doit jamais être repris : un prix vient
  toujours du backend FastAPI.
- Toutes les données sont fictives.
- Les échanges FastAPI affichés sont simulés. L'API réelle fonctionne par soumission puis
  interrogation de `/api/price/jobs/{id}`.
- Les limites de reprise sont décrites dans
  [le prompt de migration](../MIGRATION_REACT_PROMPT_CODEX_2026-11-23.md), section 8.
